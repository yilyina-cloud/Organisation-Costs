Точка верификации и участие человека

В целевом процессе основная часть сопоставления номенклатуры выполняется автоматически. Сервис интеграции автоматически получает выгрузку из купленного магазина, нормализует данные и запрашивает эталонный каталог в ERP.
Сначала выполняется точное сопоставление по штрихкоду. Если совпадение найдено, результат автоматически сохраняется и загружается в ERP без участия человека.
Для позиций, которые не удалось сопоставить по штрихкоду, сервис интеграции отправляет запрос во внешний AI-сервис. AI-сервис подбирает наиболее вероятное соответствие, после чего отдельный сервис валидации проверяет результат.
Точкой верификации является XOR Gateway «Уверенность >95%?». Если уровень уверенности выше порога, сопоставление автоматически подтверждается и загружается в ERP.
Если уровень уверенности недостаточен, позиция передаётся товароведу HQ. Товаровед проверяет только спорные позиции и при необходимости исправляет сопоставление. После ручной проверки подтверждённый результат также загружается в ERP.
Таким образом, человек участвует в процессе только при исключениях. Большая часть номенклатуры обрабатывается автоматически: сначала через точное сопоставление по штрихкоду, затем через AI-сопоставление и независимую валидацию.
После завершения сопоставления новые позиции добавляются в корпоративную систему, а обновлённые данные передаются в базы магазинов в рамках последующего обновления.
